# 屏幕 OCR 客户端（离线 · 全屏一键识别）

一个常驻后台的 Windows 屏幕取字小工具。提供两种识别模式：**全屏一键识别**（抓取整屏识别全部文字）与**区域多选识别**（拖拽框选多个区域，仅识别区域内容并以换行隔开）。两者均用本地 OCR 引擎识别中英文 / 字母 / 数字，自动复制到剪贴板，并弹出结果窗口支持「框选复制」与「一键复制全部」。**全程离线，不依赖任何云端 API。**

## 功能特性

- **全局快捷键触发**：即使焦点在其它软件上也能唤起识别。
- **全屏一键识别**：抓取主显示器（或全部显示器）整屏，自动 OCR。
- **区域多选识别**（新增）：按快捷键进入框选模式，可拖拽框选**多个区域**，仅识别各区域中的内容；**多个区域之间自动以换行隔开**。适合只取屏幕上某几块文字、跳过无关内容。
- **选区预设（多选区·一键触发）**：用 `Ctrl+Shift+1`~`Ctrl+Shift+9` 把屏幕上某块区域（可框选多个）**存为命名选区**并落盘；之后按 `Ctrl+Alt+1`~`Ctrl+Alt+9` 即可**一键自动截该区域 → OCR → 静默复制到剪贴板**，无需每次重画。适合反复取同一处固定文字（字幕条、计时器、比分牌、表单框等）。
- **一键复制全部**：识别完成后整段文本自动写入剪贴板，可直接粘贴。
- **选择复制**：弹出原生结果窗口，鼠标框选任意部分后 `Ctrl+C` 即可复制；也可点「复制全部」按钮。
- **ESC 关闭当前弹窗**：结果窗口弹出时按 `ESC` 直接关闭；区域 / 定义模式进行中按 `ESC` 取消当前选区。两种情况都**不退出程序**——程序退出统一通过**系统托盘右键「退出」**菜单，避免在其它软件中误按 `ESC` 关掉整个程序。
- **离线引擎**：基于 [RapidOCR](https://github.com/RapidAI/RapidOCR)（ONNX 推理），内置模型，无需联网。

## 使用说明

启动后控制台会常驻监听，并显示当前配置（快捷键、识别范围等）。

| 操作 | 效果 |
|---|---|
| 按 `<ctrl>+<alt>+o>` | 全屏识别：抓取屏幕 → OCR 识别 → 自动复制全部 → 弹出结果窗口 |
| 按 `<ctrl>+<alt>+r>` | 进入**区域选择**模式：屏幕变暗，鼠标框选多个区域 |
| 区域模式中 左键拖拽 | 框选一个区域（可多次拖拽，支持多选） |
| 区域模式中 右键 / `Enter` | 确认：仅识别各区域内容，区域间以换行隔开，自动复制并弹窗 |
| 区域模式中 再次按 `<ctrl>+<alt>+r>` | 取消本次区域选择（重选） |
| 区域模式中 按 `ESC` | **取消当前选区**（不退出程序），回到待机 |
| 区域模式中 `Backspace` | 撤销上一个已框选区域（需窗口获得焦点） |
| 在结果窗口中框选文字 + `Ctrl+C` | 复制选中部分（选择复制） |
| 点结果窗口「复制全部」按钮 | 复制整段文本 |
| 点「关闭」或标题栏 X | 隐藏结果窗口（下次识别再显示） |
| 结果窗口可见时 按 `ESC` | **关闭结果窗口**（不退出程序） |
| 按 `ESC`（区域 / 定义模式进行中） | 取消当前选区，回到待机（**不退出程序**） |
| 系统托盘右键「退出」 | 退出整个程序 |
| 按 `Ctrl+Shift+1`~`9` | 进入**定义选区**模式：拖拽框选（可多选）→ 确认后存为「选区 N」并写入 `region_presets.json` |
| 定义模式中 左键拖拽 / 右键 / `Enter` / `Backspace` / `Esc` | 与区域模式一致（框选 / 确认 / 撤销 / 取消），取消则本次不保存 |
| 按 `Ctrl+Alt+1`~`9` | **触发选区 N**：自动截该槽位区域 → OCR → 静默复制到剪贴板，并弹出轻量 Toast 提示（不抢焦点，约 1.6 秒后自动消失）；控制台同步打印日志 |

典型流程：
- **全屏模式**：常驻后台 → 看到想复制的文字 → 按 `<ctrl>+<alt>+o>` → 自动复制 → 切换目标窗口 `Ctrl+V` 粘贴；如需只取某几行，从结果窗口框选复制。
- **区域模式**：按 `<ctrl>+<alt>+r>` → 左键拖拽框选需要的若干块文字（每块一次拖拽）→ 右键确认 → 各块文字按区域顺序拼接、以换行隔开并自动复制；只识别你框选的范围，屏幕其它内容被忽略。

## 选区预设（一键取字）

把屏幕上**固定的一块/几块区域**存成「预设选区」，之后用快捷键一键自动识别并复制，省去每次拖拽。

1. **定义**：按 `Ctrl+Shift+1`（或 2~9），屏幕变暗进入框选，拖拽框选需要的区域（可多次拖拽框多个），右键 / `Enter` 确认。确认后该区域被存为「选区 1」并写入 `region_presets.json`。
2. **触发**：之后每次想取这块文字，只需按 `Ctrl+Alt+1`，程序自动截取已存区域 → OCR → 静默复制到剪贴板，可直接 `Ctrl+V` 粘贴；屏幕右下角会弹出轻量 Toast 提示（如 `选区1(槽位1)：已复制 N 行`，约 1.6 秒后自动消失，且不抢走当前窗口焦点），控制台同步打印日志。
3. **重定义 / 取消**：再次按同一个 `Ctrl+Shift+N` 可重新框选覆盖；框选过程中按 `ESC` 取消（不保存）。

> 预设坐标以「显示器左上角」为原点。若改了屏幕分辨率 / 显示器布局，建议重新定义对应选区。
> 选区别名（名称）默认 `选区N`，如需改名可直接编辑 `region_presets.json` 中对应条目的 `name` 字段。

## 快捷键设置（托盘弹层）

除了改 `main.py` 顶部常量，还可以**在系统托盘右键菜单点「快捷键设置...」**，弹出原生设置窗口：

- 每一项（全屏识别 / 区域选择 / 关闭取消 / 选区触发 / 选区定义）都有「录制」按钮；
- 点「录制」后按下新组合键即可捕获，再点一次「录制」可取消录制；
- **冲突即时提示**：若两个动作绑定了同一组合（例如把「全屏识别」设成 `Ctrl+Alt+1`，而「选区触发 1」默认也是 `Ctrl+Alt+1`），窗口底部会立刻标红提示；
- 点「确定」保存时**再次校验**，存在冲突会弹窗阻止并列出冲突项；
- 配置落盘到 `hotkeys.json`（与程序同级），**重启后保留**，无需改代码；
- 「恢复默认」一键还原内置默认快捷键。

> 设置即时生效：保存后会重新注册全局热键，不必重启程序。若新组合被系统/其它软件占用导致注册失败，会弹窗提示并自动回退到原设置。

## 配置说明

所有配置集中在 `main.py` 顶部「配置区」，按需修改后重新运行即可：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `HOTKEY` | `<ctrl>+<alt>+o` | 全屏识别触发快捷键；也可在托盘「快捷键设置」里改并即时生效 |
| `REGION_HOTKEY` | `<ctrl>+<alt>+r` | 区域选择模式快捷键：进入框选 / 再次按下取消本次选择；同上可托盘内修改 |
| `MONITOR` | `1` | `1` = 主显示器；`0` = 全部显示器（拼接大图，4K 下较慢）；区域选择也限定在该显示器范围内 |
| `AUTO_COPY_ALL` | `True` | 识别后是否自动复制全部到剪贴板；设 `False` 则只弹窗手动选择 |
| `SHOW_WINDOW` | `True` | 是否弹出结果窗口（支持框选复制） |
| `REGION_ALPHA` | `160` | 区域选择遮罩暗化不透明度（0-255，越大越暗，仅影响框选时的视觉遮罩） |
| `PRESET_SLOTS` | `9` | 选区预设槽位数（1~9），决定可绑定 `Ctrl+Alt/Shift+1`~`9` 的数量 |
| `PRESET_FILE` | `region_presets.json` | 选区预设落盘文件，存坐标/显示器/名称，重启后自动加载 |

> 快捷键语法遵循 `pynput`：`+` 连接组合键，`<ctrl>` `<alt>` `<shift>` `<esc>` 等为按键名。

## 常见问题

**Q：运行报错 `ModuleNotFoundError: No module named 'tkinter'`？**
A：旧版本使用 tkinter 弹提示，已改为 `pywin32` 原生窗口，不再依赖 tkinter。请确认已安装 `pywin32`（`pip install pywin32`）。

**Q：双击 `run.bat` 提示找不到路径 / 乱码？**
A：`.bat` 必须是纯 ASCII 且使用 CRLF 换行，否则中文 Windows 的 `cmd` 会误读。当前 `run.bat` 已为最小启动器（仅一行调用 PowerShell），不会出现该问题。

**Q：识别速度？**
A：首次启动会加载 ONNX 模型（约 1 秒）；之后每次热键识别通常 1 秒左右（含整屏截屏）。`MONITOR=0` 抓取全部显示器会明显变慢。

**Q：支持多显示器吗？**
A：支持。将 `MONITOR` 改为 `0` 可抓取全部显示器并拼接识别（注意性能）。区域选择模式同样以 `MONITOR` 为准——框选范围限定在该显示器内，跨显示器的区域需将 `MONITOR` 设为 `0`。

**Q：区域选择模式下怎么选多个区域？**
A：按 `<ctrl>+<alt>+r>` 进入框选，左键拖拽一次框一个区域，可连续拖拽框多个；右键（或窗口获得焦点时按 `Enter`）确认，各区域文字按框选顺序拼接并以换行隔开。想去掉刚画错的区域按 `Backspace` 撤销；想整轮重来，再次按 `<ctrl>+<alt>+r>` 取消。

**Q：区域模式和全屏模式的区别？**
A：全屏模式识别整屏所有文字；区域模式只识别你框选的若干块，且多个区域之间用换行分隔，适合只取屏幕上特定几处文字、跳过无关内容。

**Q：能识别表格 / 复杂版面吗？**
A：RapidOCR 为行列文本识别，适合一般文字抓取。如需版面分析（表格、排版还原），可后续替换为 PaddleOCR 的 PP-Structure（引擎已抽象，便于切换）。

## 打包为桌面应用（Windows 10 / 11）

本项目可打包为**单文件夹桌面程序**：系统托盘常驻、无黑框控制台、双击即跑，兼容 Windows 10 / 11 64 位。

### 构建环境
- Windows 10 / 11（构建机即目标平台，无需跨平台）
- Python 3.13（或 3.9+）隔离 venv
- 依赖：`requirements.txt` + `pyinstaller` + `pystray`（托盘，依赖 `pillow`）

### 构建步骤
```bat
:: 1) 建隔离 venv 并安装依赖（首次）
C:\Users\microsnow\.workbuddy\binaries\python\versions\3.13.12\python.exe -m venv build_venv
build_venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller pystray

:: 2) 打包（单文件夹 onedir）
build_venv\Scripts\python.exe -m PyInstaller -y ocrclient.spec
```
产物位于 `dist/OCRClient/`：
- `OCRClient.exe` —— 启动器（双击即运行，无控制台窗口）
- `_internal/` —— 全部依赖与 ONNX 模型（**必须与 exe 一起保留、整体复制**）

### 运行时形态
- 启动后在**系统托盘**显示图标，右键菜单含「关于 / 快捷键」「退出」。
- **单实例**：同一台电脑只能运行一个实例。再次双击 `OCRClient.exe` 会弹出「屏幕OCR 已在运行。」提示并退出，避免多开冲突（此约束仅对打包后的桌面形态生效，开发/控制台模式不受影响）。
- **首次启动弹「关于」**：程序按机器记录首次运行状态（`%APPDATA%\ScreenOCR\firstrun.done`），首次打开会自动弹出「关于 / 快捷键」窗口；之后不再自动弹出（删除该标记文件可重新触发）。
- 全局热键与脚本版完全一致（见上）。`ESC` 用于**关闭 / 取消当前弹窗**（结果窗口或选区），**不会退出程序**；托盘「退出」干净结束进程。
- OCR 模型（RapidOCR 三个 ONNX）已内置，全程离线。
- 启动日志（含报错）重定向至 `dist/OCRClient/ocrclient.log`，便于排障。

### 兼容性
- 目标：Windows 10 / 11 64 位。当前在 Windows 11 构建为 64 位 exe。
- 若需在较早的 Windows 10（如 1809 之前）运行，建议改用 Python 3.11 构建以最大化兼容；Python 3.13 运行时要求 Windows 10 22H2 及以上。
- 分发：复制整个 `dist/OCRClient/` 文件夹即可，无需安装；如需“正式安装包”可用 Inno Setup / NSIS 包装。

### 注意
- `region_presets.json` 在打包后写入 `dist/OCRClient/`（与 exe 同级），重定义选区会更新该文件。
- 杀毒软件可能对 PyInstaller 产物误报，属正常现象；如需消除可对 exe 进行代码签名。
